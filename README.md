\# Лабораторная работа №1 — Введение в Python



Репозиторий содержит выполненные задания в рамках лабораторной работы №1 по дисциплине «Алгоритмы и структуры данных» (или вашему предмету). 



\## 📌 О проекте



В ходе работы были выполнены 11 практических заданий, направленных на изучение базового синтаксиса Python: работа с числами, строками, списками, кортежами, словарями, множествами, функциями и модулями.



Проект реализован на трёх уровнях сложности:

\- \*\*Rare\*\* — базовая реализация всех 11 заданий.

\- \*\*Medium\*\* — инкапсуляция логики в функции, создание верхнеуровневого модуля с консольным интерфейсом (`main.py`).

\- \*\*Well-done\*\* — покрытие функциональности unit-тестами с использованием фреймворка `pytest`.

\## 🚀 Установка и запуск



\### 1. Клонирование репозитория



```bash

git clone <URL\_вашего\_репозитория>

cd LR1

```



\### 2. Создание виртуального окружения (рекомендуется)



\*\*Windows:\*\*

```bash

python -m venv venv

venv\\Scripts\\activate

```



\*\*macOS / Linux:\*\*

```bash

python3 -m venv venv

source venv/bin/activate

```



\### 3. Установка зависимостей



```bash

pip install -r requirements.txt

```



\*(Файл `requirements.txt` содержит только `pytest>=7.0.0`, так как остальные модули — стандартная библиотека Python).\*

\## 🧪 Тестирование (Well-done)



Тесты написаны с использованием `pytest` и находятся в едином файле `test\_tasks.py`.



Для запуска тестов выполните из корня проекта:



```bash

python -m pytest test\_tasks.py -v

```



\*(Использование `python -m pytest` гарантирует, что тесты запустятся даже если `pytest` не добавлен в PATH).\*



Ожидаемый вывод:

```text

test\_tasks.py::test\_task1 PASSED                                         \[ 18%]

...

test\_tasks.py::test\_task10 PASSED                                        \[100%]



============================== 11 passed in 0.05s ==============================

```

\## 🛠️ Особенности реализации



1\. \*\*Импорт модулей с цифрами в имени:\*\* так как файлы заданий начинаются с цифр (например, `00\_distance.py`), стандартный `import` невозможен. В `main.py` и `test\_tasks.py` используется `importlib.import\_module('tasks.00\_distance')`.

2\. \*\*Пакетирование:\*\* папка `tasks` содержит файл `\_\_init\_\_.py`, что делает её полноценным пакетом Python.

3\. \*\*Перехват вывода в тестах:\*\* для проверки результатов в `test\_tasks.py` используется `io.StringIO` и `contextlib.redirect\_stdout`, что позволяет тестировать консольный вывод функций `main()`.
